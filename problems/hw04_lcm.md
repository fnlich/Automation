# Homework 04: Least Common Multiple

**Topic:** Number Theory
**Difficulty:** Simple

## Problem

Write a function `lcm(a, b)` that returns the least common multiple of two
positive integers `a` and `b`. You may reuse the `gcd` function from
Homework 03.

## Input

Two positive integers `a` and `b`.

## Output

An integer: the least common multiple of `a` and `b`.

## Example

```
Input:  a = 4, b = 6
Output: 12
```
