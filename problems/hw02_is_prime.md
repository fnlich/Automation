# Homework 02: Is Prime

**Topic:** Number Theory
**Difficulty:** Simple

## Problem

Write a function `is_prime(n)` that returns `True` if `n` is a prime number,
and `False` otherwise.

## Input

A single integer `n`.

## Output

A boolean: `True` if `n` is prime, `False` otherwise.

## Example

```
Input:  n = 17
Output: True

Input:  n = 18
Output: False
```
