# Homework 18: Sum of a List (Recursive)

**Topic:** Recursion
**Difficulty:** Simple

## Problem

Write a function `sum_list(arr)` that returns the sum of all numbers in a
list using recursion (no loops, no built-in `sum()`).

## Input

A list of numbers, e.g. `[1, 2, 3, 4, 5]`.

## Output

A number: the sum of all elements in the list.

## Example

```
Input:  arr = [1, 2, 3, 4, 5]
Output: 15
```
