# Homework 19: Reverse a String (Recursive)

**Topic:** Recursion
**Difficulty:** Simple

## Problem

Write a function `reverse_string(s)` that returns the reverse of a string
`s` using recursion (no loops, no slicing shortcuts like `s[::-1]`).

## Input

A string `s`, e.g. `"hello"`.

## Output

A string: `s` reversed.

## Example

```
Input:  s = "hello"
Output: "olleh"
```
