# Homework 11: Selection Sort

**Topic:** Sorting
**Difficulty:** Simple

## Problem

Write a function `selection_sort(arr)` that sorts a list of numbers in
ascending order using the selection sort algorithm.

## Input

A list of numbers, e.g. `[64, 25, 12, 22, 11]`.

## Output

A new list containing the same numbers, sorted in ascending order.

## Example

```
Input:  arr = [64, 25, 12, 22, 11]
Output: [11, 12, 22, 25, 64]
```
