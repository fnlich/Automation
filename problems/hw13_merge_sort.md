# Homework 13: Merge Sort

**Topic:** Sorting
**Difficulty:** Middle

## Problem

Write a function `merge_sort(arr)` that sorts a list of numbers in
ascending order using the merge sort algorithm (divide and conquer).

## Input

A list of numbers, e.g. `[38, 27, 43, 3, 9, 82, 10]`.

## Output

A new list containing the same numbers, sorted in ascending order.

## Example

```
Input:  arr = [38, 27, 43, 3, 9, 82, 10]
Output: [3, 9, 10, 27, 38, 43, 82]
```
