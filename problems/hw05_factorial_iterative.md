# Homework 05: Factorial (Iterative)

**Topic:** Number Theory
**Difficulty:** Simple

## Problem

Write a function `factorial(n)` that computes `n!` (n factorial) using a
loop (no recursion). By definition, `0! = 1`.

## Input

A non-negative integer `n`.

## Output

An integer: `n!`.

## Example

```
Input:  n = 5
Output: 120   # because 5! = 5 * 4 * 3 * 2 * 1 = 120
```
