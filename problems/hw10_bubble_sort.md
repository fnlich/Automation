# Homework 10: Bubble Sort

**Topic:** Sorting
**Difficulty:** Simple

## Problem

Write a function `bubble_sort(arr)` that sorts a list of numbers in
ascending order using the bubble sort algorithm.

## Input

A list of numbers, e.g. `[5, 2, 9, 1, 5, 6]`.

## Output

A new list containing the same numbers, sorted in ascending order.

## Example

```
Input:  arr = [5, 2, 9, 1, 5, 6]
Output: [1, 2, 5, 5, 6, 9]
```
