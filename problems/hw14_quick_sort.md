# Homework 14: Quick Sort

**Topic:** Sorting
**Difficulty:** Middle

## Problem

Write a function `quick_sort(arr)` that sorts a list of numbers in
ascending order using the quicksort algorithm (choose the last element
of each sub-list as the pivot).

## Input

A list of numbers, e.g. `[10, 7, 8, 9, 1, 5]`.

## Output

A new list containing the same numbers, sorted in ascending order.

## Example

```
Input:  arr = [10, 7, 8, 9, 1, 5]
Output: [1, 5, 7, 8, 9, 10]
```
