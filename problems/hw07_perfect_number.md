# Homework 07: Perfect Number Checker

**Topic:** Number Theory
**Difficulty:** Middle

## Problem

A **perfect number** is a positive integer that is equal to the sum of its
proper divisors (all positive divisors excluding the number itself).

Write a function `is_perfect_number(n)` that returns `True` if `n` is a
perfect number, and `False` otherwise.

## Input

A positive integer `n`.

## Output

A boolean: `True` if `n` is a perfect number, `False` otherwise.

## Example

```
Input:  n = 28
Output: True   # divisors: 1, 2, 4, 7, 14 -> sum = 28

Input:  n = 12
Output: False  # divisors: 1, 2, 3, 4, 6 -> sum = 16
```
