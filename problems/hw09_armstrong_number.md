# Homework 09: Armstrong Number Checker

**Topic:** Number Theory
**Difficulty:** Middle

## Problem

An **Armstrong number** (also called a narcissistic number) is a number
that equals the sum of its own digits, each raised to the power of the
number of digits.

Write a function `is_armstrong(n)` that returns `True` if `n` is an
Armstrong number, and `False` otherwise.

## Input

A positive integer `n`.

## Output

A boolean: `True` if `n` is an Armstrong number, `False` otherwise.

## Example

```
Input:  n = 153
Output: True   # 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153

Input:  n = 123
Output: False
```
