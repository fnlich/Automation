# Homework 12: Insertion Sort

**Topic:** Sorting
**Difficulty:** Simple

## Problem

Write a function `insertion_sort(arr)` that sorts a list of numbers in
ascending order using the insertion sort algorithm.

## Input

A list of numbers, e.g. `[12, 11, 13, 5, 6]`.

## Output

A new list containing the same numbers, sorted in ascending order.

## Example

```
Input:  arr = [12, 11, 13, 5, 6]
Output: [5, 6, 11, 12, 13]
```
