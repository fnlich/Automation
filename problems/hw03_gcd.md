# Homework 03: Greatest Common Divisor

**Topic:** Number Theory
**Difficulty:** Simple

## Problem

Write a function `gcd(a, b)` that returns the greatest common divisor of two
positive integers `a` and `b`, using the Euclidean algorithm.

## Input

Two positive integers `a` and `b`.

## Output

An integer: the greatest common divisor of `a` and `b`.

## Example

```
Input:  a = 48, b = 18
Output: 6
```
