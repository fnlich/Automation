# Homework 08: Prime Factorization

**Topic:** Number Theory
**Difficulty:** Middle

## Problem

Write a function `prime_factors(n)` that returns a list of the prime
factors of `n` (with repetition), in ascending order.

## Input

An integer `n` with `n >= 2`.

## Output

A list of integers: the prime factors of `n`, including duplicates.

## Example

```
Input:  n = 60
Output: [2, 2, 3, 5]   # because 60 = 2 * 2 * 3 * 5
```
