# Homework 17: Fibonacci (Recursive)

**Topic:** Recursion
**Difficulty:** Simple

## Problem

Write a function `fibonacci(n)` that returns the `n`-th Fibonacci number
using recursion, where `fibonacci(0) = 0` and `fibonacci(1) = 1`.

## Input

A non-negative integer `n`.

## Output

An integer: the `n`-th Fibonacci number.

## Example

```
Input:  n = 6
Output: 8   # sequence: 0, 1, 1, 2, 3, 5, 8
```
