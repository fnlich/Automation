# Homework 01: Sum of Digits

**Topic:** Number Theory
**Difficulty:** Simple

## Problem

Write a function `sum_of_digits(n)` that takes a non-negative integer `n` and
returns the sum of its digits.

## Input

A single non-negative integer `n` (e.g. `n = 12345`).

## Output

An integer: the sum of the digits of `n`.

## Example

```
Input:  n = 12345
Output: 15   # because 1 + 2 + 3 + 4 + 5 = 15
```
